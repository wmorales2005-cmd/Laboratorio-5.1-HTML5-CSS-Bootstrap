TAREA 5.1 - CREACIÓN DE UNA PÁGINA WEB RESPONSIVA CON CSS
Estudiante: Wilfredo Morales

DESCRIPCIÓN
Este proyecto es un sitio web responsivo desarrollado con HTML5, CSS3 y Bootstrap 5.
Incluye una página de inicio, un portafolio, una página de contacto y páginas de detalle
para cada proyecto.

ARCHIVOS PRINCIPALES
- index.html: página de inicio con navegación, encabezado, Acerca de mí y botón a contacto.
- portfolio.html: presenta proyectos mediante tarjetas Bootstrap.
- contacto.html: formulario con nombre, correo, mensaje y validación Bootstrap.
- proyecto1.html, proyecto2.html, proyecto3.html: detalles de cada proyecto.
- css/estilos.css: estilos personalizados y regla responsive.
- images/: imágenes SVG utilizadas por el sitio.

CÓMO ABRIRLO
1. Descomprime el archivo ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html con Live Server o directamente en un navegador.
4. Prueba los enlaces Inicio, Portafolio y Contacto.
5. Reduce el ancho de la ventana para demostrar el diseño responsivo.
